## 重新下载

```bash
node tools/fetch-irasutoya.mjs
node tools/fetch-anime-assets.mjs
```

第一个脚本重建原有 17 件素材，第二个脚本补充本作 18 件合作方头像并更新为 35 件清单，同时把下一作品的 18 件写入独立目录。图片 CDN 不可直连时，第二个脚本仅在下载阶段通过公共图片代理获取公开原图；游戏运行时不使用代理或外链。
